# Protocol documents

The manufacturer's RS-232 documents the adapter is written from. PDFs and the logo sources are
git-ignored: they are CTOUCH / i3-CONNECT's documents, kept locally as reference. CTOUCH is now
i3-CONNECT; older models keep the CTOUCH name.

| Model | Document | Family | Supported |
|---|---|---|---|
| Laser Nova, Laser Sky | RS-232 protocol for CTOUCH Laser Nova + Laser Sky, V4.02 (CTOUCHimPD1381V191113) | a9 | yes |
| Riva R2 | CTOUCH Riva R2 RS232 protocol V230414 | a9 | yes |
| Neo | Neo RS232 specification v1.3 | a9 | yes |
| Cactus | i3CONNECT RS232 Specification Cactus v1.2 | i3 | yes |
| Veneer 2 | i3CONNECT RS232 Specification Veneer 2 v1.0 | i3 | yes |
| Walnut W1 | i3CONNECT RS232 Specification Walnut W1 v1.0 | own (checksummed, UDP 8600) | not yet |
